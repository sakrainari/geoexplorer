# GeoExplorer

「世界をストリートビューで散歩しながら、解説・うんちくを楽しむ図鑑サイト」

## 入力ツール

スポットマスター・解説シートのデータを入力するためのWebツールです。

- GoogleマップURLから緯度・経度を自動取得
- タグ・世界遺産登録基準をチェックボックスで選択
- スポットマスター（A〜S）・解説シート（A〜N）の全項目を入力
- 入力内容をTSV／JSONでコピー可能

バニラ JS / HTML / CSS のみで構成された静的ファイルです。

### 公開URL（GitHub Pages）

```
https://<ユーザー名>.github.io/geoexplorer/
```

### ローカルで開く

`index.html` をブラウザで開くだけで動作します。
